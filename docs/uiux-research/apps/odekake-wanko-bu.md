# おでかけわんこ部 UI/UX調査
- 調査日: 2026-08-05 / 調査者: AI（Claude subagent）

## 概要とターゲット（運営・プラットフォーム・規模感）
- 運営: 株式会社tent tent（大阪市中央区、代表取締役: 小西恵子）[出典: tent-tent.jp]
- 「おでかけわんこ部」は月間50万〜70万人が利用する国内最大級の愛犬とのおでかけ情報メディア（Webサイト・Instagram等のSNS群が先行し、2026-01-09に公式アプリをリリース）[出典: lit.link, PR TIMES]
- アプリはiOS版のみ（App Store: iOS 15.1以降、iPhone/iPad/Mac（Apple M1以降）/Apple Visionに対応）、67.9MB、無料、カテゴリ「ライフスタイル」、年齢制限16+ [出典: App Store]
- 評価4.2/5・20件（2026-08-05時点の調査で確認したレビュー日付は2026-01-08〜2026-04-01の範囲）[出典: App Store]
- 掲載スポットは「全国5,000件以上」のペット同伴OKスポット（カフェ・宿泊施設・観光スポット・ドッグラン・道の駅・サービスエリア・夜間対応動物病院など）[出典: odekake-wanko-bu.com/app/, PR TIMES]
- 前身として「おでわんMAP」というWeb版地図サービスが存在（無料メルマガ登録が閲覧条件、リリース時点で1,400件超掲載）。アプリはそのWeb版からの移行先という位置づけで、実際に「WEB版はバグが多かったがアプリになって使いやすくなった」というレビューも存在する（推測: Web版からアプリへの本格移行が2026年1月の狙いだった可能性）[出典: tent-tent.jp, App Storeレビュー]
- 「Wan!Pass（ワンパス）」という別の愛犬同伴施設アプリと業務提携し、相互にレポート記事リンクを設置（提携内容の詳細な信頼性担保の仕組みは公開情報からは不明）[出典: PR TIMES]

## 主要フロー（起動→探す→詳細→行動、の流れ）
公式サイト・プレスリリースの説明ベースでの推測を含むフロー（実機未検証、スクリーンショット非公開のため画面遷移の詳細は未確認）:
1. 起動 → 地図（MAP検索）が主導線。「スマホを開くたびに、今いる場所が『愛犬と楽しむ場所』に変わる」という現在地起点の体験を想定 [出典: PR TIMES]
2. 探す → MAP上で「店内OK」「大型犬可」「テラス席あり」等の条件で絞り込み、カフェ/飲食店・宿泊施設・観光施設・ドッグラン・キャンプ場・道の駅・サービスエリアなどカテゴリを選択 [出典: odekake-wanko-bu.com/app/, tent-tent.jp]
3. 詳細 → スポットのピンをタップして詳細情報・過去の「おでかけログ（口コミ・写真レポート）」を閲覧（推測: 前身の「おでわんMAP」でも「アイコンをタップすると詳細情報とレビューへのリンクが見られる」という同様の操作体系だったため、アプリでも踏襲されている可能性が高い）[出典: Geolonia]
4. 行動 → 「行きたい」リストへの保存（要ログイン）、訪問後に写真付きで「おでかけログ」を投稿してコミュニティに共有 [出典: odekake-wanko-bu.com/app/]
- 「部員登録」（メールアドレス+パスワード）をするとお気に入り保存・口コミ投稿が可能になる、いわゆる「閲覧は無料・投稿はログイン必須」という段階的な会員化フローと見られる [出典: odekake-wanko-bu.com/app/]
- 有料の「プレミアム部員」（月額500円）に登録すると、マイページ＞プロフィールに「プレミアム部員証」が表示され、提携施設での提示で優待・限定クーポンが使える（アプリ内課金またはサブスクと推測されるが詳細な決済導線は不明）[出典: tent-tent.jp]

## 地図・一覧・検索フィルタのUIパターン
- 前身「おでわんMAP」の説明が最も具体的: カテゴリごとにピンのアイコンを変えて視覚的に区別（例: 飲食店/ホテル・宿/ドッグラン、後に水族館は魚アイコンなど）。「見た目もわかりやすく」という設計意図が明言されている [出典: Geolonia]
- 現在地起点の検索が「非常に喜ばれている」機能として名指しされており、旅行中でも「今いる場所からすぐにスポットを探せる」という現在地優先のUXが強みとされている [出典: Geolonia]
- アプリでは「MAP検索や条件絞り込み」で「今行ける場所」「旅先で寄れる場所」を直感的に探す設計思想が明言されている（一覧（リスト）表示の有無や地図とリストの切り替えUIについては、公開情報からは確認できず）[出典: odekake-wanko-bu.com/app/]
- フィルタ条件として確認できたもの: 「店内OK」「大型犬可」「テラス席あり」。カテゴリとして: カフェ・飲食店／ドッグラン（日常利用）、宿泊施設（ホテル）・キャンプ場・観光施設（旅行・レジャー）、道の駅・サービスエリア（移動支援）、夜間対応動物病院（緊急時対応）という分類がプレスリリースで整理されている [出典: PR TIMES, odekake-wanko-bu.com/app/]
- 検索の絞り込みUIの具体的な見た目（フィルタチップ/ボトムシート/検索バー等の形式）はスクリーンショットが取得できなかったため未確認（要追加調査: 実機インストールでの確認を推奨）

## 詳細画面の情報設計（何をどの順で見せるか）
- 詳細画面の情報構成について、公開情報から具体的な項目順序（電話番号・営業時間・地図・写真の配置順など）は確認できなかった（推測に留める箇所が多いため以下は限定的な記述）
- 確認できた要素: スポット詳細ページに「おでかけログ（口コミ）」へのリンクが表示される、詳細ページ自体は運営側で「自由にカスタマイズできる」仕組みになっており広告枠（楽天トラベル等）も組み込み可能という記述がある（ただしこれは前身のWeb版「おでわんMAP」に関する記述で、アプリの詳細画面と完全に同一かは不明）[出典: Geolonia]
- 夜間対応動物病院は「現在地から近い」順に地図で確認できる、という緊急時ユースケースに特化した見せ方が明言されている（通常のカフェ等のスポットと同じ詳細画面フォーマットかは不明）[出典: PR TIMES]

## 写真・ビジュアルの見せ方
- コンテンツの核は「全国の飼い主様からの情報提供（クチコミ・写真レポート）」であり、実際の利用者が投稿した写真付きレポートを中心に構成している（公式の商業写真ではなくUGC＝ユーザー投稿写真が主体という設計）[出典: tv-tokyo.co.jp検索結果, tent-tent.jp]
- 「おでかけログ」投稿機能を通じて訪問した場所に写真付きで記録・共有する体験が用意されている [出典: odekake-wanko-bu.com/app/]
- レビューでも「実際の経験談がほとんどなのでリアルにイメージできる」「お店の宣伝じゃないし実際のレポートだから参考になる」という声があり、ユーザー投稿写真・体験談ベースの見せ方がアプリの評価点として認識されている [出典: App Store, WebSearch要約]
- 具体的な写真のレイアウト（グリッド/カルーセル等）やカメラロール連携の有無は未確認

## 信頼性・情報鮮度の見せ方（出典・確認日・口コミの扱い）
- 情報源は二重構造: (1) 「おでかけわんこ部特派員」による現地調査、(2) 全国の飼い主からの情報提供（クチコミ・新規スポット登録）。いずれも「スタッフが確認し随時反映」する運用体制が明言されている [出典: tent-tent.jp]
- 「日本一温かい地図アプリ」を掲げ、情報の温かみ・実体験ベースであることを訴求ポイントにしている一方、確認日の表示や出典の明示（いつ時点の情報か）についての具体的な仕組みは公開情報からは確認できなかった [出典: tent-tent.jp]
- ユーザーレビューでは「掲載情報が少なすぎる」「ユーザーがワンコOKなお店を自分で追加できない」という不満も見られ、情報提供はフォーム経由でスタッフが精査してから反映する運営主導型（ユーザーが直接データベースを編集する形ではない）と推測される [出典: App Store, WebSearch要約]
- Wan!Pass（別の同種アプリ）との業務提携により相互にレポート記事リンクを設置しているが、この提携が情報の相互検証・信頼性向上を目的にしているかどうかは記事内に明記されていない [出典: PR TIMES]

## 特徴的なUXパターン・差別化ポイント
- メディア（Web/SNSで月50万〜70万人利用）が母体となっており、単体の地図アプリではなく「コンテンツメディア＋地図検索」のハイブリッド設計。UGC（口コミ・写真レポート）の蓄積量と実体験ベースの情報が最大の差別化要素として繰り返し訴求されている [出典: tent-tent.jp, App Storeレビュー]
- 日常利用（カフェ・ドッグラン）と旅行・レジャー利用（宿泊・キャンプ場・観光施設）、さらに移動支援（道の駅・SA）、緊急時対応（夜間動物病院）まで、犬との外出シーンを「日常〜非常時」まで幅広くカバーする設計思想 [出典: PR TIMES]
- 将来的に自治体と連携した「ペット同行避難所」表示機能を計画しており、防災インフラとしての位置づけも見据えている（現時点では未実装、公開情報ベースの計画段階）[出典: PR TIMES]
- 月額500円のプレミアム会員という軽量なサブスクモデルで、来店時の会員証提示による優待という比較的シンプルな収益・特典導線を採用 [出典: tent-tent.jp]
- Web版（おでわんMAP、メルマガ登録必須・1,400件超）からアプリ（ログイン任意で閲覧・5,000件以上）への移行により、閲覧のハードルを下げつつ投稿・保存機能をアカウント制にする、という段階的な会員化の設計変化がうかがえる [出典: Geolonia, tent-tent.jp, odekake-wanko-bu.com/app/]

## Puppy With Cafe への示唆（3〜5個・箇条書き）
- **UGCと運営確認のハイブリッドは信頼性訴求として有効だが、"確認日"の可視化は差別化になりうる**: おでかけわんこ部は「特派員調査＋飼い主投稿をスタッフが確認」という体制を訴求点にしているが、確認日そのものをユーザーに明示する仕組みは公開情報から確認できなかった。Puppy With Cafeは`Core/ConflictResolver`で確認日・由来(provenance)を保持している強みがあるため、詳細画面で「最終確認日」「情報源」を明示することは競合にない差別化点になりうる。
- **犬同伴可否の粒度（店内OK/大型犬可/テラス席あり）は参考になるフィルタ設計**: 同アプリの条件検索（店内OK・大型犬可・テラス席あり）は、Puppy With Cafeの`allowed/conditional/not_allowed/unverified`という可否ステータス設計と組み合わせて、フィルタUIの語彙・粒度の参考にできる（例: 「大型犬可」「テラス席のみ」等のサブ条件をカフェの補足情報として持たせるか検討の余地）。
- **「情報が少なすぎる」という不満は、掲載件数よりカバレッジの粒度・エリア偏りが原因の可能性が高い**: 5,000件掲載を謳いながらも低評価レビューで「杉並区在住だが近場で探すとGoogle検索の方がマシ」という声があった。Puppy With Cafeは268件・東京34エリアと件数では劣るが、エリア内の密度・網羅性を丁寧に作り込むことで「探しても出てこない」という不満を避けられる可能性がある。
- **緊急時（夜間動物病院）・防災（同行避難所）という"非日常"導線は地図型ペットアプリの差別化余地として学べる**: Puppy With Cafeは犬同伴カフェ探しが核だが、将来的に「近隣の動物病院」等の周辺情報レイヤーを検討する際の先行事例として参考になる（ただしスコープ拡大は要検討・現行憲章の範囲外の可能性が高いため即採用は非推奨）。
- **「投稿はログイン必須・閲覧は無料」という段階的会員化は、Puppy With Cafeの「報告はサインインなしGoogleフォーム」方針と対照的**: おでかけわんこ部はアカウント制のUGC投稿（お気に入り・口コミ）を採用しているのに対し、Puppy With Cafeは`FR-028`改訂によりサインインなしの報告フローを選んでいる。この違いは「投稿ハードルを下げて量を集める」vs「運営承認による質を担保する」というトレードオフの実例として、今後v2で報告フローを拡張する際の比較検討材料になる。
