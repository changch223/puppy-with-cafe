🐶☕ Puppy With Cafe プライバシーポリシー

最終更新日: 2026年10月27日

Puppy With Cafe（以下「本アプリ」）は、利用者のプライバシーを最大限尊重して設計されています。本アプリは、氏名・メールアドレス・位置情報などの個人情報を運営者のサーバーに送信・収集することはありません。

1. 収集しない情報

  • アカウント登録・ログインはありません。本アプリを通じて氏名・メールアドレス等の個人情報を収集しません。
  • 広告・トラッキング（追跡）は一切行いません。解析SDK・広告SDK・クラッシュ収集SDKを含みません。
  • 運営者は、利用者の利用状況・端末識別子・位置情報を取得する仕組みを持ちません。

2. 端末内で取り扱う情報（外部に送信しません）

  • 現在地: 「周辺の犬同伴可カフェを探す」機能のためだけに、利用者の許可を得たうえで（使用中のみ）取得します。現在地は各店舗までの距離の計算と地図の表示位置の決定にのみ使い、すべて端末内で完結します。外部に送信せず、キャッシュ等にも保存しません（距離も保存しません）。位置情報を許可しなくても、地域を手動で選んで利用できます。
  • 行きたい・行った: 「行きたい」「行った」に登録した店舗の識別子と、登録日・来店日を、端末内（アプリの設定領域）にのみ保存します。運営者や第三者には送信されません。
  • うちの子の設定: 「うちの子」に設定した犬の大きさ（小型犬・中型犬・大型犬）と、お店での過ごし方（床で待てる・カート／キャリー・抱っこ）を、端末内（アプリの設定領域）にのみ保存します。名前・写真・年齢などの情報は持ちません。入れるお店の判定は端末内だけで行い、運営者や第三者には送信されません。
  • 最近の検索: 検索画面（検索バー）で選んだ場所の名前と、その場所の緯度・経度を、直近5件まで端末内（アプリの設定領域）にのみ保存します。次に検索画面を開いたときに「最近の検索」として表示するためのもので、運営者や第三者には送信されません（現在地を保存するものではありません）。
  • キャッシュ: 取得したカフェ情報データ（cafes.json）と、リンク先のプレビュー（タイトル・縮小画像。最長14日）を、通信量削減とオフライン表示のために端末内に一時保存します。

3. 外部サービスとの通信

本アプリは機能の提供のため、次の外部サービスと通信します。いずれの通信にも、運営者が個人を特定できる情報は含まれません。通信時には、通常のインターネット通信と同様に、IPアドレスや端末の基本的な情報が通信先に届く場合があります。

  • カフェ情報データの取得（GitHub Pages）: 最新のカフェ情報（cafes.json）を GitHub Pages から取得します。この通信に利用者の位置情報・個人情報は含まれません。
  • Instagram 投稿の埋め込み表示（Instagram / Meta）: 店舗の詳細画面で、Instagram の公式埋め込み形式により投稿を表示する場合があります。このとき、アプリ内の表示領域（WebView）が instagram.com のスクリプトとコンテンツを読み込みます。Cookie 等は永続化しない設定で表示します。表示されたコンテンツの取り扱いは Instagram（Meta）のポリシーに従います。
  • リンク先のプレビュー取得（Apple LinkPresentation）: 店舗の公式サイト・食べログ・参考記事などのタイトルや画像を表示するため、端末が直接リンク先のサイトへアクセスしてプレビュー情報（OGP）を取得します。画像の転載・再配布は行いません。
  • 地域・駅名・住所の検索（Apple マップ）: 利用者が検索画面（検索バー）で入力した住所・駅名などの検索文字列は、検索のために Apple の地図／ジオコーディングサービスに送信されます。Apple による取り扱いは Apple のプライバシーポリシーに従います。
  • 地図の表示（Apple マップ）: 地図の表示には Apple の MapKit を利用します。
  • 経路案内（Apple マップ／Google マップ）: 利用者が「経路」を選んだ場合に限り、目的地（店舗）の座標を Apple マップまたは Google マップに渡します。出発地として現在地が使われるかどうかは、各マップアプリの設定と利用者の許可に従います。
  • 「地図で写真を見る」（Google マップ）: 店舗に写真・SNS等のリンクが無い場合、利用者が「地図で写真を見る」をタップしたときに限り、店名と住所を検索語として Google マップの検索ページをアプリ内の Safari 画面（SafariView）で開きます。現在地は渡しません。Google による取り扱いは Google のプライバシーポリシーに従います。
  • 外部リンクの表示: 店舗の公式サイト・SNS等のリンクは、アプリ内の Safari 画面（SafariView）で開きます。リンク先での情報の取り扱いは各サイトのポリシーに従います。

4. 誤り報告・お問い合わせ（メール・GitHub Issues）

  • カフェ情報の誤り報告およびお問い合わせは、メール（irairappo@gmail.com）と GitHub Issues で受け付けています。メールでお問い合わせいただいた場合、運営者はそのメールアドレスと本文を受け取ります。これらは返信と掲載情報の確認のためだけに使い、第三者に提供・販売しません。アプリはメールアドレスを自動で送信しません（利用者ご自身がメールを送った場合に限ります）。
  • GitHub Issues は、運営者とは別の事業者（GitHub, Inc.）が提供するサービスで、利用には GitHub アカウントが必要です。投稿時の情報の取り扱いには GitHub のプライバシーに関する声明が適用されます。本アプリを通じて運営者が利用者の情報を収集することはありません（Issues は、利用者ご自身が GitHub 上で書き込む場合に限り、その内容を運営者が読むことになります）。
  • Issues に書いた内容は公開されます。氏名・メールアドレス・電話番号などの個人情報は書き込まないでください。運営者は、投稿内容を掲載情報の修正およびお問い合わせへの対応のためだけに読み・利用します。
  • 本アプリの現在の版には、誤り報告のためのボタンやフォームは含まれていません。専用フォームは準備中です。
  • お問い合わせ・誤り報告: メール irairappo@gmail.com ／ GitHub Issues https://github.com/changch223/puppy-with-cafe/issues

5. 第三者提供・トラッキング

  • 運営者は、利用者の情報を第三者に提供・販売・共有しません（本アプリを通じては、そもそも収集していません。メールでのお問い合わせの内容は返信と確認のためだけに使います。GitHub Issues に利用者自身が書き込んだ内容は公開されます）。
  • 本アプリは、利用者を他社のアプリやウェブサイトをまたいで追跡（トラッキング）しません。

6. データの保存期間と削除方法

  • 端末内の情報（行きたい・行った・うちの子の設定・最近の検索・キャッシュ）は、お使いの端末にのみ保存されます。アプリを削除すると、これらはすべて削除されます。
  • 「行きたい」「行った」は、アプリ内で個別に解除できます。「うちの子」の設定は、「うちの子」タブからいつでも変更できます。「最近の検索」は新しい検索で入れ替わり（直近5件のみ保持）、個別に消す操作はありません。アプリを削除すると消えます。
  • 位置情報の許可は、iOS の「設定」アプリからいつでも変更・取り消しできます。
  • 運営者側に利用者の情報は保存されていないため、運営者側で削除する情報はありません。

7. 掲載情報について

  • 掲載しているカフェ情報（犬同伴可否・営業時間等）は、出典と確認日を明示した収集時点の情報です。最新の情報や犬同伴の最終確認は、各店舗の公式情報や店舗へ直接ご確認ください。

7-2. 出典・クレジット

  • 位置情報（地図上の座標）の一部は、デジタル庁「アドレス・ベース・レジストリ」（公共データ利用規約（第1.0版）参照）を Puppy With Cafe 運営が加工して作成しています。

8. 改定・お問い合わせ

  • 本ポリシーを改定する場合は、本ページで告知します。
  • お問い合わせ: メール irairappo@gmail.com ／ GitHub Issues（GitHub アカウントが必要です。内容は公開されるため、個人情報は書かないでください）／サポートページ
