## 仕様

- 必須サイズ: **6.9 インチ（iPhone 17 Pro Max など）= 1320 × 2868 px**。iPhone 専用アプリなので 6.9" の 1 サイズだけ必須。**5 枚**を基本に（最大 10 枚）。他サイズは 6.9" から自動縮小される。
- 外観はライトで統一（ダークも出すなら同じ場面を別セットで）。文字サイズは標準（`large`）。
- 本番の `cafes.json` を配信した状態で撮る（**架空・サンプルデータの店が写らないこと**。画面に「サンプルデータ表示中」のバナーが出ていたらやり直し）。
- 画面に載せるキャプション（上部の帯）は任意。載せる場合は下記の文言を使い、誇張しない（「必ず入れる」「全店確認済み」などは書かない）。

余裕があれば 6〜7 枚目: ⑥ ピンをタップしたときの店のカード（答えの1行と、経路・電話・行きたい・共有）、⑦「うちの子」タブ（設定とピンの見かた＝色と形の凡例）。

## 準備（ターミナル）

```bash
# 1. シミュレータ: Xcode > Window > Devices and Simulators で iPhone 17 Pro Max を追加して起動
# 2. 撮影前の準備
xcrun simctl status_bar booted override --time 9:41 --batteryState charged --batteryLevel 100 --cellularBars 4 --wifiBars 3
xcrun simctl location booted set 35.6595,139.7005      # 渋谷駅付近（周辺にカフェが並ぶ）
xcrun simctl privacy booted grant location com.dokowancafe.app   # 位置情報の許可ダイアログを出さない
xcrun simctl ui booted appearance light
xcrun simctl ui booted content_size large              # 標準の文字サイズ
# 3. 撮影
mkdir -p ~/Desktop/shots
xcrun simctl io booted screenshot ~/Desktop/shots/01_now.png
# 4. サイズ確認（すべて 1320 × 2868 であること）
sips -g pixelWidth -g pixelHeight ~/Desktop/shots/*.png
# 5. 後片付け
xcrun simctl status_bar booted clear
```

- 位置情報の許可ダイアログが出たままだと画面が隠れるので、`privacy grant` を先に実行する。ダイアログが固まったときはシミュレータを一度シャットダウンして起動し直す。
- 「うちの子」は場面 1・3 で設定済みの状態が必要。アプリの「うちの子」タブ（または初回の2問）で「小型犬」を選んでおく。名前などは入力しない（聞かない）。
- 場面 2 は日付が実行日で変わる（「土」の選択肢は今日から 6 日先まで）。曜日が出ない日は「明日」でもよい。

## 選ぶ店の目安

- 営業時間・答えのカード・根拠（出典と確認日）がそろっている店を選ぶ（情報が空の店を避ける）。
- 画像に実在店の外観写真・Instagram 埋め込みが写る場合は、権利面で避けるか、写真が出ない店（先頭が小さな地図の帯になる店。例: 公式リンクのない店）を選ぶ。写真プレビューは端末が各店のページから直接取得する仕組みで、画像の転載・再ホストはしていないが、ストア画像として固定されるので慎重に。
- 「確認日が古い」「出典に食い違いあり」の警告が付く店は、場面 4 以外では避ける（警告を見せるなら場面 4 の説明として）。
