## 説明文（1010字 / 4000字以内）

方針: 誇張しない。憲章 原則I「出典つき・推測しない」を価値として前面に出す。件数は変動するため本文に固定数を書いていない（現在 594 件・2026-10 時点。書く場合は更新時に差し替え）。

```
愛犬と一緒に入れるカフェを、地図でさっと探せるアプリです。

行ってみたら犬は入れなかった、という残念な思いをしないために。Puppy With Cafe は、犬の同伴可否を「出典」と「確認日」つきで掲載し、確認できていないことは推測せずに「未確認」と表示します。

【できること】
・現在地周辺、または選んだ地域の「犬と行けるカフェ」を地図とリストで表示
・犬の同伴可否を「犬OK／条件付き／未確認」で色分け。条件（サイズ・席の種類・ケージの要否など）もあわせて掲載
・「店内OK」「テラスOK」「大型犬OK」「犬メニューあり」で絞り込み
・距離順、または確認日が新しい順に並び替え
・営業時間と「営業中」の目安表示（営業時間が確認できた店舗のみ）
・店舗ごとに、犬同伴可否の根拠となった出典の種類と確認日を表示
・電話、公式サイト、Instagram、食べログなどへのリンク
・気になるお店を肉球ボタンでお気に入りに保存（端末内のみ）
・Apple マップ／Google マップへの経路案内
・情報の誤りを見つけたら、店舗の詳細画面からフォームで報告

【情報の考え方】
・犬の同伴可否は、店舗の公式サイトや公式SNSなど、出典を確認できた情報をもとに運営が整備しています。
・確認できない項目は「未確認」とし、推測で「OK」にはしません。
・店舗ごとに確認日を表示します。古い情報は、お出かけ前に最新の状況をご確認ください。
・掲載情報は目安です。犬の同伴可否や条件は変更されることがあるため、来店前に必ず店舗へ直接ご確認ください。

【プライバシー】
・ログイン・アカウント登録は不要です。
・現在地は「使用中のみ」の許可で、周辺のカフェと距離の表示にだけ使います。端末内で処理し、外部に送信・保存しません。
・広告・解析・トラッキングは行いません。
・位置情報を許可しなくても、「渋谷」「新宿」「吉祥寺」などの地域や駅名・住所を選んで使えます。

【対象エリア】
現在は東京都内のカフェを掲載しています。今後、掲載するお店とエリアを少しずつ広げていく予定です。

【ご注意】
・掲載店舗の情報は収集時点のものです。営業時間・定休日・犬の同伴条件は予告なく変わることがあります。
・地図上の座標の一部は、デジタル庁「アドレス・ベース・レジストリ」を Puppy With Cafe 運営が加工して作成しています。
```
