## 説明文（937字 / 4000字以内。運用上の目安は 1024 字以内）

方針: 誇張しない。憲章 原則I「出典つき・推測しない」を価値として前面に出す（「うちの子OK」も、お店の情報に明記があるときだけ出すことを書く）。件数は変動するため本文に固定数を書いていない（書く場合は更新時に差し替え）。

```
愛犬と一緒に入れるカフェを、地図でさっと探せるアプリです。

行ってみたら犬は入れなかった、という残念な思いをしないために。Puppy With Cafe は、犬の同伴可否を「出典」と「確認日」つきで掲載し、確認できていないことは推測せずに「未確認」と表示します。

【できること】
・地図の上の検索バーで、店名・駅名・エリアから探す（現在地の周りも選べます）
・「いつ行く？」で日時（今日から1週間以内）を選ぶと、その時間に開いているお店だけを表示
・「うちの子」の大きさ（小型・中型・大型）と店内での過ごし方を設定すると、入れると明記されたお店に「うちの子OK」を表示（設定は端末内のみ）
・お店の詳細では「店内で一緒に過ごせます」「テラス席で一緒に過ごせます」などの答えを最初に表示し、その根拠（出典の種類と確認月）も一目で分かります
・「店内OK」「テラス」「大型犬OK」「犬メニュー」でも絞り込み
・気になるお店は「行きたい」、行ったお店は「行った」に保存（端末内のみ）
・電話、公式サイト、Instagram、食べログへのリンク。Apple マップ／Google マップへの経路案内、共有

【情報の考え方】
・犬の同伴可否は、公式サイト・公式SNS・食べログ・犬連れ向けの紹介記事などの出典を運営が確認し、確認日と一緒に表示します（出典の種類は店ごとに異なります）。
・確認できない項目は「未確認」「情報なし」とし、推測で「OK」にはしません。うちの子が入れるかも、お店の情報に明記があるときだけ「OK」と表示します。
・掲載情報は目安です。同伴条件や営業時間は変わることがあるため、来店前に店舗へご確認ください。

【プライバシー】
・ログイン・アカウント登録は不要。広告・解析・トラッキングはありません。
・現在地は「使用中のみ」の許可で、周辺のお店と距離の表示にだけ使い、端末内で処理します。送信も保存もしません。許可しなくても、駅名やエリアを指定して使えます。

【対象エリア】
現在は東京都内のカフェを掲載しています。順次広げていきます。

【ご注意】
地図上の座標の一部は、デジタル庁「アドレス・ベース・レジストリ」を運営が加工して作成しています。
```

## 補足

- アプリ名は表示名（`INFOPLIST_KEY_CFBundleDisplayName`）と同じ「Puppy With Cafe」。ほかのアプリと重複して取得できない場合は「Puppy With Cafe - 犬とカフェ」等に変更（30字以内）。
- 「What's New（このバージョンの新機能）」初回は不要。2回目以降に記入。
- 説明文の機能一覧は 2026-10-26 時点（再設計 段階4）のアプリ実装に基づく: 検索バー（店名・駅・住所・エリア）／条件チップ（いつ行く？・うちの子OK・営業中・店内OK・テラス・大型犬OK・犬メニュー）／3段の一覧シートとピンのカード／詳細の答えのカードと根拠の1行／行きたい・行った（保存タブ）／うちの子タブ（設定・データ更新日・ピンの見かた・このアプリについて）／経路（Apple・Google）・電話・共有。機能を変えたら更新する。
- 動作環境は iOS 17 以降（`IPHONEOS_DEPLOYMENT_TARGET = 17.0`）。
- スクリーンショット内にも「推測しない・出典と確認日」が伝わる画面（店詳細の答えのカード＋根拠）を入れる（撮影の場面と順番は `screenshots.md`、全体の手順は `submission-checklist.md` 参照）。
