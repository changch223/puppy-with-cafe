### バッチA: 未確認59件の可否再調査 【開始済み 2026-08-07】
- 対象: `dog_policy_status = unverified` の59件（一覧: 調査時に `data/master/cafes.csv` から抽出）
- ゴール: 公式サイト・公式SNS・信頼できる媒体で犬同伴可否を確認し、`allowed/conditional`（出典・確認日付き・provenance=aggregated）へ更新。確認できなければ unverified のまま（**憶測禁止**）。廃業が判明したら `is_closed` を報告

## 依頼方法

- 本リポジトリの cafe-researcher（`.claude/agents/cafe-researcher.md`）に「バッチ○を実施して」と依頼。ルールは `research-agent/README.md`（推測禁止・出典と確認日必須・provenance=aggregated・画像転載禁止）に厳密に従うこと

- 反映＝運営レビュー後に commit → push（push で GitHub Pages 配信）
