# データギャップ補完 ハンドオーバー（研究エージェント向け・2026-08-08 / 総数594件）

既存594件の**未収集項目を埋める**調査依頼。新規カフェの追加ではなく、**既存カフェ行の空欄を埋める**作業。
まず必ず `research-agent/README.md`（絶対ルール）と `tools/README.md`（CSV列仕様）を読むこと。

## 絶対ルール（README.md より・厳守）
- **推測禁止**。確認できた事実のみ記入。確認できなければ**空欄のまま**（空欄＝不明であり「不可/なし」ではない）。
- 犬同伴可否・設備に関わる事実は**出典URL＋確認日が必須**。`sources.csv` に出典行を追加する。
- provenance は **`aggregated` 固定**。source type は `official_hp / sns / google_map / tabelog / blog / other` のいずれか。
- **画像・文章の転載禁止**。事実を自分の言葉で要約し出典URLを添えるのはOK。食べログ/Googleは「記載の有無を確認して事実とURLを記録」に留める。
- **コミットしない**。作業は `data/master/cafes.csv` / `data/master/sources.csv` の該当行を編集するだけ。運営がレビューして反映＝承認。
- 自己検証: 編集後に `python3 tools/export_cafes.py --check` を実行し **0エラー**を確認してから納品する。CSVは `csv.DictReader/DictWriter` で列順・クオート・改行を保つこと。

## 対象行の特定
既存行の編集なので、**id または name で行を一意特定**して該当セルだけ埋める（他列・他行は触らない）。同名が複数ある場合は area/sub_area/address で区別し、区別できなければスキップして報告。

## バッチD: 営業時間の構造化（テキストのみ446件＋情報なし73件）
- **D-1（Web調査ほぼ不要・機械変換）**: `hours_text` があり構造化列が空の446件。`hours_text` の原文を各曜日列へ構造化する。
  - **記入列**: `hours_mon … hours_sun` に `H:MM-H:MM`（**24時間表記**・時は先頭ゼロなし・分は2桁・複数帯はカンマ区切り・時刻順 例 `11:00-15:00,17:00-22:00`、`9:30-18:00`）。定休日は `定休`、不明は空欄。
  - **注意（重要・2026-08-08改訂）**: 深夜営業・日跨ぎ営業も構造化列に入れられる。閉店は `24:00`（当日終端＝翌0:00）まで許可し、日跨ぎ営業は開店>閉店（例 `18:00-2:00`、翌1:00閉店なら `17:30-1:00`）でそのまま入力する（`OpeningHoursEvaluator` が日跨ぎ区間を正しく判定する）。`17:00-24:00` は「24:00終端（開店<閉店、当日の終端まで営業）」の表記で、日跨ぎとは別。開店==閉店（例 `18:00-18:00`）はタイプミス扱いでエラーになるため、24時間営業は `0:00-24:00` と明示すること。
  - `hours_text` が曖昧・複雑で機械変換が難しいものは無理に構造化せず残す。
  - **変換ルール要点（2026-10・RULES.md）**:
    - L.O.（ラストオーダー）は無視し閉店時刻を使う。「〜時刻(L.O.)」のように閉店でなくL.O.しか書かれていない帯は閉店不明として扱い、その曜日は空。ただし同じ時間帯を閉店時刻つきの別の帯が覆っている場合はその帯を使ってよい（例: カフェ 11:30〜23:00 がレストランの L.O. のみの帯を含む）。
    - 祝日・祝前日は無視（曜日列のみ。「土日祝」→土・日、「金土祝前日」→金・土）。
    - 定休曜日が明記されていれば `定休`。「年中無休」「不定休」「施設に準ずる」は時間を入れてよい（定休にしない）。
    - 曜日指定のない時刻だけで定休日情報が皆無なら**構造化しない**（全曜日空。休みの日に営業中と誤表示するため）。
    - 曜日を列挙し一部に言及がない曜日は空（定休と推測しない）。
    - 時刻が確定しない・例示のみ（「〜など」「曜日により異なる(例…)」「季節変動」等）は skip（全曜日空）。
    - **不確定語**（など・要確認・要公式確認・要最新確認・例・時期により・日により・季節・曜日により・推定・変動あり・変更あり・変更の場合あり）が**営業時間そのもの、または週の定休曜日**にかかる場合は全曜日空（holiday 由来の `定休` も入れない）。年末年始休業・不定休の**告知方法**にかかる語（例「不定休（SNSで要確認）」「年末年始休業(要確認)」）は対象外。
    - 境界: 特定の月だけの変更（例「8月は営業時間変更あり」「2月のみ時短」）は年末年始と同様に許容。時期を特定しない変更（「時期により時短営業あり」）は不採用。「基本水曜定休」のような「基本」は許容。
    - `holiday_note` が「年末年始のみ」「元日のみ」等で週の定休が無いと読める場合は、全曜日に時間を入れてよい（運営判断 2026-10）。
    - 隔週休み（第2・第4火曜休み等）はその曜日を空にし、他曜日は通常どおり。推測は一切しない。
  - **運用（二重独立変換）**: 同じ原文を2つの変換担当が独立に変換し、**mon〜sun の7値が完全一致かつ1曜日以上が非空の店だけ採用**して `cafes.csv` に反映。1曜日でも不一致、または両方全空の店は不採用（不一致は一覧化して後続で目視・再変換）。**一致後も、原文（`hours_text` / `holiday_note`）との突き合わせ QA を必須**とする（二重変換で同じ誤りが一致しうるため）。
- **D-2（要調査）**: 営業時間情報が全く無い73件。公式サイト/食べログ/Googleで確認して `hours_text`（＋可能なら構造化列）を埋める。
- 効果: アプリの「営業中」バッジ・「営業中優先」ソートが実用になる。
